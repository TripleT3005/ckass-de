# ckass.de

Persönliche Website.

Die Website zeigt nur den Namen „ckass“, dessen Buchstaben ihre Schriftstärke dezent wellenförmig ändern und auf Maus oder Berührung reagieren. Das Farbschema folgt dem Hell-/Dunkelmodus des Geräts.

Die Seite ist rein statisch (HTML, CSS und ein wenig JavaScript) und kommt ohne externe Ressourcen, Cookies und Tracking aus. Verwendet wird die Systemschrift des Geräts.

---

Personal website.

The website shows only the name "ckass". Its letters subtly change weight in a wave and react to mouse or touch. The color scheme follows the device's light/dark mode.

The site is fully static (HTML, CSS and a little JavaScript) with no external resources, cookies or tracking. It uses the device's system font.
